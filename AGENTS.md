# Product UI/UX skill repository

- For UI/UX, research, Persian/RTL, design systems, or UX measurement work, read `.agents/skills/product-ui-ux/SKILL.md` and its relevant references.
- Distinguish observed UI, hypotheses, author claims, and actual user findings.
- This is a skill package, not a running product. Do not invent an application stack or install all referenced tools.
- Keep portable relative links inside the skill. Keep captures and private product data out of Git.
- Check browser automation with `python -m unittest discover -s tests -v`; report skips.
